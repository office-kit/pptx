The Format pane starts closed, as in PowerPoint, and opens from the object menu's Format Shape… / Format Picture… / Format Chart Area… / Format Video… / Size and Position…, from Format Background…, or from a Format Pane button. Once open it follows the selection: objects show their format, the slide shows Format Background (with the slide options below it).
